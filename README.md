## About This Project

This project is a React-based MealDB application that integrates TMDB API to fetch meals of different categories.

This project focuses on:

- React state management
- Clean and readable UI interactions
- API integration
- Data Fetching

## Built With

- ReactJS
- npm
- vercel
- Ky
- zustand

### Prerequisites

Knowledge about JS, ReactJS, Ky, npm, vite, Zustand and tailwindcss

- Basic data structures
- Arrays
- useEffect
- Functions
- objects

## Clone Project

- To get a local copy up and running follow these simple example steps.
- Clone this repository with `git@github.com:Chu29/meals-db.git` using your terminal or command line.
- Change to the project directory by entering: `cd meals-db` in the terminal.

## Command line steps

- $ git clone `git@github.com:Chu29/meals-db.git`
- $ `meals-db`
- $ `git checkout development`

## Start App

- run `npm install`
- run `npm run dev` in your command line
